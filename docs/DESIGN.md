# DESIGN

## 产品定位

Onion Flow（简称 Onion）是一个面向 macOS 的 notch-style / Dynamic Island 风格音乐 mini player，并带线上发现、歌词和局域网遥控等扩展能力。

目标不是做普通通知条，而是做一个贴合屏幕顶部边缘、接近 MacBook 刘海交互感的原生悬浮音乐控制组件。

## 设计目标

- 顶部中央常驻
- 视觉上贴合屏幕顶部
- 默认状态简洁克制
- 当前阶段支持本地播放列表、线上发现 / 播放、歌词、快捷启动、临时暂存与紧凑播放控制
- 整体接近 macOS 原生质感

## 形态定义

### Compact

用于常驻展示核心状态。

特点：

- 单行信息
- 顶部贴边
- 黑色 notch-style 外形
- 不像 notification banner

布局（从左到右）：

- 左侧 Mascot 角色区域（32pt × 32pt，compact 距左边缘 10pt，expanded 顶栏距左边缘 15pt）
- 右侧收起态音乐活动指示 / 展开态工具按钮组（compact 距右边缘 14pt，expanded 顶栏距右边缘 20pt）
- Mascot 和右侧状态 / 工具区域保持左右分离，不互相侵占空间

建议内容：

- 收起态：左侧 Mascot 角色动画（收起 → idle，展开 → working）、右侧音乐活动指示
- 展开态：左侧 Mascot music 状态动画（4 到 6 个环绕音符按周期错位变化）、右侧工具按钮组

### Expanded

当前用于显示音乐 mini player。点击 expanded 空白区域会收起 island。

当前显示：

- 当前曲名
- 播放状态
- 播放 / 暂停
- 上一首 / 下一首
- 顺序 / 单曲循环 / 列表循环 / 随机播放模式
- 进度条
- 当前时间 / 总时长
- 本地曲库 / 线上发现 / 歌词标签页
- 添加本地文件 / 音乐目录、清空播放列表
- 快速启动 App 槽位
- 当前会话临时暂存

## 视觉规范

### 背景

- 主背景接近纯黑
- 建议：`Color.black.opacity(0.94)`
- 可加入非常轻的顶部高光

### 阴影

- expanded 状态使用较明确的外侧黑色投影：`Color.black.opacity(0.9)`，`radius: 8`，`x: 0`，`y: 0`
- compact 状态不显示阴影
- expanded 状态保留外侧黑色投影；compact 状态不显示阴影

### 圆角

- 顶部：应与顶部屏幕边缘融合
- 底部：使用较大圆角
- 当前底部圆角：compact `15`，expanded `40`

### 底部边缘间距规范 (Premium Gap Specification)

为了在灵动岛底部大圆角（`40pt`）下避免界面元素产生被切角的拥挤感，并维持高品质的悬浮和呼吸美感，整个灵动岛底部的留白规范进行了极致的简化与高度统一：
* **临时暂存开启状态**（底部最外侧是临时暂存）：因为临时暂存虚线框向下偏移了 `8pt`（用于贴紧底部），因此其容器底部留白（`currentBottomPadding`）应设定为 **`12pt`**，从而在视觉上留出完美的 **`4pt`**（12 - 8）精致呼吸边距。
* **临时暂存关闭状态**（底部最外侧是播放列表或快捷启动）：无论开启了播放列表、快捷启动，还是两者同时开启，底部留白统一设定为经典的 **`26pt`**，从而使界面底沿留出非常舒展、开阔的视觉空间，维持极佳的视觉张力与大圆角呼吸感。
* 对应的灵动岛展开窗体高度（`expandedHeight`）已针对各状态进行了数学微调，彻底消除了底部多余的黑色空白区。

### 形状要求

- 不能是普通 `RoundedRectangle`
- 优先采用 notch-style 自定义 `Shape`
- 目标是：
  - top attached
  - flat top edge
  - concave shoulder corners
  - rounded bottom corners
- 肩部半径跟随展开状态动画过渡（compact 5 → expanded 10）
- 底部圆角同样跟随状态变化（compact 15 → expanded 40）

## 交互规范

### 基础交互

- 点击 compact 状态栏展开
- 再次点击 compact 顶栏或点击 expanded 空白区域收起；点击桌面或其它 App 不收起
- 展开采用两阶段动画：先扩大 AppKit 窗口，再展开 SwiftUI 壳体
- 内部点击收起时先收回 SwiftUI 壳体，再把 AppKit 窗口缩回 compact
- expanded 透明区域必须透传鼠标事件，避免阻挡桌面或其它 App
- expanded 高度变化必须保持顶部贴边；高度使用整数对齐，避免小数 frame 造成 1pt 上下跳动

### 音乐播放交互

- 收起态 compact 保持 Mascot / 右侧音乐活动指示
- 选择本地音乐并播放后，收起态 compact 仍保持 Mascot / 右侧音乐活动指示
- 所有音乐控制只放在 expanded mini player 中，compact 不放播放 / 暂停、进度等音乐控制
- expanded mini player 支持混合添加本地文件和目录、拖拽添加本地文件和文件夹、播放 / 暂停、上一首 / 下一首、切换顺序 / 单曲循环 / 列表循环 / 随机模式、点击播放列表项、删除列表项、清空列表和拖动进度；线上发现页支持网易云榜单、搜索、个人歌单、相似推荐和在线歌曲播放，歌曲列表与播放失败状态仅在当前 App 会话内缓存，退出或刷新后清空
- 关闭播放列表 / 歌词区域后，expanded 收缩为更紧凑的顶部控制 + 进度条形态，并在顶部 overlay 显示当前歌词单行。该单行歌词采用 `10pt` 常规（regular）字重，并配以单层 `0.58` 不透明度、`3.5` 半径的翠绿霓虹发光投影，兼顾字形纤细清秀与微光指示灯质感；快捷启动和临时暂存是否继续显示由各自独立布局开关决定
- 歌词检查会在当前曲目加载、expanded 面板出现、播放列表 / 歌词布局切换、歌词标签页或遥控状态读取时触发：本地文件 / 已确认缓存优先；在线搜索受设置开关控制。滚动歌词字体采用极简清雅规格，激活当前行字号降为 **`11.8pt` (bold)** 附带 `1.04` 倍平滑膨胀与 `.shadow` 呼吸微光，普通行字号降为 **`9.8pt` (regular)**，纵向间距紧致为 **`10`**，在 `117pt` 紧凑卡片内形成极富空气感的精美排版。当无本地或缓存歌词且开启联网时，系统会采用基于 Jaccard 相似度的高级融合匹配算法（综合计算标题 and 歌手的非空单词交并比，并对歌名精准匹配进行加成），自动比对候选列表并下载融合度最高（排序第 1 位）的歌词进行静默加载展示；如果自动下载失败或用户觉得自动匹配不对，点击“重新匹配”即可呼出完整排序后的在线候选列表供用户自主挑选确认。
- 收起态右侧音乐活动指示（频谱仪）提供 4 种可无缝切换的高精质感视觉风格，满足用户的个性化偏好，并支持跨启动的 `@AppStorage` 持久化保存：
  1. **翡翠晶柱 (Columns - "columns")**：经典的 5 栏垂直向上跳动晶柱，带翡翠绿霓虹外发光与白荧光高光，暂停时折叠为 5 颗极简水平基底晶体点。
  2. **极简声波 (Sound Wave - "wave")**：优雅流动的水漾多重正弦谐波曲线，振幅与微震由中低高音频段实时调制，暂停时完美回弹收敛为一条半透明水平直线。
  3. **灵动呼吸 (Breathing - "breathing")**：中间一颗悬浮的极简胶囊舱，尺寸和发光投影深度随重拍发生高频弹性形变与呼吸起落，暂停时收缩为一颗超微型极简小药丸。
  4. **科幻脉冲 (Symmetrical Pulse - "pulse")**：极富未来感对称美学的 5 栏垂直双向拉伸律动晶柱，暂停时收敛为 5 根极短的微型垂直小晶针。
- 所有频谱风格的切换交互均采用极简的单色灰度 (Monochromatic Gray) 段选择器主题表现，位于“Onion 设置”页下半部的偏好设置区域内，其选中与 Hover 状态拥有极其流畅的物理弹簧动画回馈。
- expanded mini player 的播放器按钮、播放列表播放按钮、删除按钮和清空按钮都提供悬停提示词
- expanded mini player 在没有加载列表时仍保留播放列表区域，空态需明确提示可以拖拽歌曲或文件夹
- 快速启动 App 面板完全为空时显示主副引导文案；已有 App 或拖入悬停时显示 10 个固定槽位：空槽使用弱化占位，每次仅接收一个外部 App，拖入时仅高亮鼠标指向的目标槽；外部 App 拖到空槽放置、拖到已有图标替换；已有 App 使用系统原生拖拽图像跟随鼠标，拖到空槽移动、拖到已有图标交换，并保留中间空位。为了更加精致紧凑，快速启动容器取消了静态外框与动态拖入拖出的容器底盘及虚线框，让网格槽位直接融入灵动岛黑底中。每个槽位尺寸从 38x38 缩小至 32x32 并使用 7pt 的小圆角。拖入拖出的反馈色（包括目标槽位 Hover 高亮背景与描边、占位加号图标、占位投影、以及已有 App 替换高亮边框等）统一采用与临时暂存完全一致的极简单色灰度（Monochromatic Gray）主题（利用不同不透明度的半透明白色 `Color.white.opacity(...)` 表现），避免高饱和度色彩（如蓝色或紫色）抢夺界面主视觉
- 临时暂存位于快捷启动下方，使用接近 Finder 的单行横向图标架：为了与快捷启动面板高度对齐，临时暂存同样取消了静态与动态的外框背景及边框线，让文件卡片直接融入灵动岛黑底中。可生成预览的文件显示 Quick Look 缩略图，无法预览时回退系统文件图标，原始名称位于下方，项目较多时横向滚动；接受任意文件 / 文件夹 的单个或多个拖入，可原生拖出到 Finder 或其它 App，成功拖出后自动移除对应引用
- 临时暂存拖入反馈可向 expanded 底部壳体内扩展并贴近底边，但不得改变 island 总高度、底部圆角或外侧阴影；圆角外和阴影区不作为投放区域
- 临时暂存采用 Finder 风格选择语义：单击单选，`Command` 增减选择，`Shift` 选择连续范围，空白区域拖动可框选；默认拖入记录为移动，按 `Option` 拖入记录为复制，并在图标右下角以极简黑白色调、无外边框线、常规字重（不加粗）的微型胶囊徽章（“移”采用珊瑚红半透明 0.24 opacity 背景，“拷”采用翡翠绿半透明 0.24 opacity 背景，前景色均为高对比度纯白）提供清晰而现代的 HUD 视觉反馈；拖动任意已选项可批量拖出，以单色灰度（Monochromatic Gray）选中态、叠放预览和数量角标提供反馈
- 临时暂存的头部标题采用无框扁平布局（Flat Typography），无胶囊状边框及背景填充，使用常规字重（regular）以实现轻量优雅的现代排版。右侧的“一键清空”（垃圾桶）按钮采用完全扁平化设计，无任何圆形背景或边框，悬浮 Hover 时图标由空心 `"trash"` 形变为实心 `"trash.fill"` 并呈现明亮珊瑚红（Coral Red, `#FA5959`），且仅在 Hover 时图标和悬停状态呈现红色，视觉效果与播放列表项的删除按钮完全保持一致
- 所有交互反馈（包含拖入热区虚线框、选中框选框、项目选中背景/描边、复选标记圆圈、拖出预览数量角标等）统一采用极简的单色灰度（Monochromatic Gray）主题（利用不同不透明度的半透明白色 `Color.white.opacity(...)` 表现），避免高饱和度色彩（如蓝色或紫色）抢夺界面主视觉
- 移 / 拷混合选择时即时提示“移 / 拷暂不支持混合，请分开拖出”，并阻止混合批量拖出；为保持顶部 island 的非激活面板交互，不要求通过获取键盘焦点响应 `Esc`
- 临时暂存中的单项移除与清空不删除源文件；外部失效路径以不可用状态呈现并允许移除
- 三个拖入区域语义独立：播放列表导入音乐、快捷启动配置 `.app`、临时暂存保存任意文件引用
- 用户关闭快捷启动后不显示其标题、分割线或槽位，播放列表 / 歌词内容区域扩展以占用释放的高度；临时暂存保持可见，重新开启时恢复原槽位布局
- 用户关闭临时暂存后不显示其标题、暂存区或底部分割线，并同步收缩 expanded 高度，避免底部留出过多空白
- 当前阶段仅为歌词匹配和线上展示读取标题 / 歌手 metadata，不做最近曲目、专辑封面、系统媒体键或复杂资料库

### 右侧工具按钮交互

- 右侧工具按钮只在展开后显示
- 静音按钮只切换 Onion 内部播放器静音状态，不修改系统音量；悬停音量区域会展开微型音量条，调大音量时自动解除 Onion 内部静音
- 设置按钮切换 Onion 设置页的打开 / 关闭状态，悬停提示词随当前状态显示“打开设置”或“关闭设置”
- 退出按钮直接退出 Onion
- 按钮 hover 时只增强背景和描边，不做缩放

### Onion 设置页交互

- 菜单栏 "Settings..." 打开设置窗口；Onion 设置按钮可再次点击关闭窗口。
- 灵动岛从 expanded 收起到 compact 时，若设置窗口仍处于打开状态，应同步关闭。
- 窗口外形：宽度固定为 `440pt`、高度随当前设置内容自适应的无边框透明面板（NSPanel），关闭“氛围背景”时采用极富质感、完全不透明的深炭灰纯色背景（Color(red: 0.04, green: 0.04, blue: 0.06)），仅标题栏区域可拖动，并在失去焦点时自动关闭。
- 角色与频谱卡片选择：
  - 采用 4 列自适应弹性网格（`GridItem(.flexible(), spacing: 12)`），卡片高度固定为 `66pt`，宽度支持 `.infinity` 弹性拉伸（拉伸后单卡约为 `89pt`），确保角色、频谱卡片左右侧的物理边缘与下方的偏好设置、性能卡片保持 100% 绝对对齐，呈现极其优美的统一左右边距（24pt），无需滚动条以防溢出裁切。
  - 卡片中的角色展示 `idle` 动画预览，便于选择前确认角色表现。
  - 点击卡片可实时切换灵动岛常驻角色，选中卡片点亮该 Mascot 专属色调的散射发光投影与高亮边框。
- 偏好设置选项（位于设置页下半部）：
  - **氛围背景**：支持开启/关闭灵动岛展开态的渐变氛围背景，开启时水平展开 10 种配色供快速切换；选择后设置页背景同步预览。配色按钮在悬浮 Hover 时拥有 `1.15` 倍放大与对应色彩发光的反馈。
  - **联网匹配歌词**：默认关闭；开启后在本地与已确认缓存均不可用时才在线搜索，触发时机包括当前曲目加载、expanded / 歌词 UI 和遥控状态读取。
- 性能与效果选项（独立卡片分组）：
  - **动态粒子**：支持开启/关闭漂浮粒子，并明确提示关闭可降低 GPU 占用。
- 布局快捷开关（位于 expanded 底部 overlay）：
  - **播放列表 / 歌词**：默认开启；关闭后隐藏播放列表 / 歌词卡片，进入更紧凑的播放控制形态并显示当前歌词单行。
  - **快捷启动**：默认开启；关闭后隐藏 expanded 底部的快捷启动，并自动调整 expanded 高度和 drop 路由。
  - **临时暂存**：默认开启；关闭后隐藏 expanded 底部的文件暂存 / 拖出区域，并自动调整 expanded 高度和 drop 路由。
- 性能约束：
  - 设置窗口覆盖顶部 island 时关闭 `NSPanel` 原生阴影，以避免已复现的额外窗口合成开销。
  - 设置页角色预览恢复动画后，应继续观察打开设置窗口时的 GPU 占用。

### 播放列表交互

- 播放列表项点击播放对应曲目
- 播放列表项左侧显示序号，当前播放项使用蓝色序号和曲名
- 播放列表项不使用行间虚线分隔，依靠文字层级、hover / 选中背景和外层边界区分行
- 播放列表项 hover / 选中背景使用蓝色低透明整行矩形背景，不带圆角
- 播放列表项显式使用箭头光标，避免停在文字上显示输入光标
- 删除按钮 hover 时显示红色背景提醒，点击删除对应曲目
- 播放列表文字使用细体（regular 字重）
- 播放列表区域保持低透明背景和虚线边框；空播放列表状态额外显示拖拽提示和辅助说明
- 拖拽文件或文件夹进入播放列表区域时显示低透明蓝色填充和虚线描边，只作为 drop target 提示

### 后续交互方向

- Mascot 点击交互（当前阶段预留，不绑定动作）

## 动画建议

- 使用短时长 spring 动画
- 展开时优先做高度和透明度过渡
- 避免夸张缩放

## 技术约束

文件职责、数据流和模块边界以 `docs/ARCHITECTURE.md` 为准；本文档只保留会影响产品体验的设计约束。

### Mascot

- 纯 SwiftUI Canvas + TimelineView，不引入 Lottie / SpriteKit / PNG sprite sheet
- 不创建 MascotViewModel，状态由 `viewModel.isExpanded` 和 `musicViewModel.state` 直接映射
- MascotView 使用 `.allowsHitTesting(false)`，不阻断 compactBar 点按
- 默认尺寸 32pt，设置页当前不提供尺寸切换
- 角色视觉采用高阶矢量曲线、线性与径向渐变、高透镜面反光质感以及外发光阴影特效，在 32pt 极致物理限制下保留精细的微观反光、动态骨骼颤动与极佳的可识别度。

## 当前关注点

- 音乐 mini player 播放列表、线上发现和歌词阶段已完成基础接入
- 当前阶段支持单曲、多曲、目录和拖拽文件 / 文件夹添加到当前播放列表，支持网易云榜单 / 搜索 / 个人歌单入口，并在下次启动恢复本地列表、播放模式和上次播放进度；线上发现歌曲列表及其播放失败状态不跨启动恢复
- expanded 状态保持在同一个 island 壳体内
- 当前渲染层已拆分为 `ContentView`、`CompactIslandView`、`ExpandedIslandView` 与 `NotchIslandShape`，后续视觉调整应保持单层壳体边界
- 后续扩展前继续保持播放控制集中在 expanded mini player

## 设计优先级
